Cara saya mengerjakan proyek

Saya tulis kerangka halaman dulu dengan tag semantik, baru memikirkan tampilannya.

Bootstrap saya pasang offline dari folder plugin, jadi halaman tetap tampil rapi tanpa koneksi internet. Grid dan komponennya membantu halaman cocok di HP dan laptop.

Kode saya simpan di repository GitHub, lalu diaktifkan lewat GitHub Pages supaya bisa dibuka siapa saja lewat link.
